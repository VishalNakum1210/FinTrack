# FinTrack — signed Android release candidate

Created by Vishal Nakum. Support: daku.9705@gmail.com. No postal address is published.

Use the APK for manual Android installation; the AAB is for a future Google Play submission and cannot be installed directly. No upload or publishing is performed by the build helper.

Verify the APK against SHA256SUMS.txt. Install over the existing application with the same signing key; never uninstall or clear data to force an update. Preserve private exports before device changes. If signatures differ, stop and contact support.

Phone numbers are account identifiers, not SMS-verified identities. Profile email cannot reset a password. Support-assisted recovery requires independent ownership evidence and is not guaranteed. Exports are unencrypted; choose recipients carefully. JSON export has no in-app restore feature.

These are release candidates until the remaining checks in PLAY_STORE_RELEASE.md are completed. An AAB build does not establish Play approval or completion of Play Console testing.
